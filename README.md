# 🛡️ Cyber Threat Analytics Platform with Incident Visualization System

An interactive data analytics and visualization platform developed using **Microsoft Power BI** to analyze cybersecurity incidents, identify threat patterns, monitor incident severity, and uncover potential risk hotspots through data-driven insights.

**Project:** Infosys Springboard Virtual Internship 7.0  
**Batch:** 4  
**Domain:** Cybersecurity | Data Analytics | Business Intelligence  
**Tool:** Microsoft Power BI

---

## 📌 Project Overview

The Cyber Threat Analytics Platform aims to transform raw cybersecurity incident data into meaningful insights through interactive dashboards and visual analytics.

The platform consolidates threat incidents, emergency events, environmental risk indicators, operational response records, and contextual datasets to provide a unified analytical environment.

It helps users understand threat distributions, identify high-risk areas, monitor incident trends, and support informed security-related decision-making.

## 🎯 Project Objectives

- Analyze cybersecurity incidents based on threat severity and categories.
- Identify patterns and trends in reported security incidents.
- Detect potential threat hotspots using analytical visualizations.
- Monitor operational response and incident distribution.
- Transform raw datasets into meaningful and actionable insights.
- Develop an interactive and user-friendly Power BI dashboard.

## 🛠️ Technology Stack

| Technology | Purpose |
|---|---|
| Microsoft Power BI | Dashboard development and visualization |
| Power Query | Data cleaning and transformation |
| DAX | Calculated measures and KPIs |
| CSV / Excel | Dataset management |
| Data Analytics | Incident analysis and insights |

## 📊 Key Dashboard Features

- **KPI Cards:** High-level overview of important incident metrics.
- **Threat Severity Analysis:** Analyze incidents across different severity levels.
- **Incident Distribution:** Understand the distribution of cybersecurity threats.
- **Trend Analysis:** Identify changes in incident patterns over time.
- **Category Analysis:** Examine different threat categories.
- **Interactive Filters:** Explore data through dynamic slicers and filters.
- **Visual Insights:** Present complex incident data through interactive charts and graphs.

## 🧹 Data Preparation & Preprocessing

The initial milestone focuses on preparing a reliable dataset for analysis.

Key preprocessing activities include:

- Numerical data validation.
- Missing and invalid value handling.
- Outlier detection using the IQR method.
- Date and time formatting.
- Categorical value standardization.
- Data consistency and integrity checks.
- Column renaming and feature creation.
